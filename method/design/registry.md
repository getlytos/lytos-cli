## Rules of this register

1. Every new Design artifact is recorded here when it is created: link, nature, project, current
   version.
2. Each time a new version is read: update the current version and the table of versions and cards.
3. A version that is not implemented has a card or a "to apply" line: no version stays without a
   written follow-up.
4. A gap with what exists (inconsistent or missing) goes back to the design tool as a ready-to-paste
   prompt, and is noted in the card concerned, under "Gaps".
