# Human list: screen reader (`human:screen-reader`)

Only what no automated tool decides. The automated analysis and the keyboard walkthrough pass
first, as `auto` items.

- Journey replayed with a real screen reader (for instance VoiceOver or NVDA): does the reading
  order make sense?
- Is every state announced (error, success, loading)?
- Are the names of icon-only buttons understandable by ear?
