# lytos-cli 1.7.1

A hardening release after the two independent reviews of 1.7: edge cases of the independence check and of the discovery gate, and a few documentation fixes. No new feature.

## Exit criteria

- [ ] The configuration cannot lift the independence level at high risk through a gateway-prefixed model id
- [ ] A discovery override always records a real author, and the wrapper contract names every command that takes it
- [ ] `lyt next` never returns a card of `type: epic`
- [ ] `lyt lint` flags an approval in review that has no independence record
- [ ] The session-start and French README gaps are closed
