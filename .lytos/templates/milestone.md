# v1.0 — [What this version delivers]

*A milestone is a product-level goal: a version. It may span several sprints, and a sprint may serve
several milestones. It corresponds to a tag and a deployment, and the owner closes it by accepting
it: set `status: closed`.*

*Copy this file to `.lytos/milestones/<id>.md`; the file name is the id. An epic or a leaf joins the
milestone with `milestone: <id>` in its frontmatter. `npx lyt milestone <id>` then shows its
progress, derived from those cards: nothing is counted here by hand.*
